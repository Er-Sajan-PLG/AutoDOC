# AutoDOC / AutoDOC

The Holy Grail of Self-Updating, AI-Aware Software Documentation.

## The Vision
"Every document that *should* exist for a software project exists here. Every document that *can* be automated is automated. Every document that *must* stay current is automatically verified, updated, or flagged whenever any change is made to the project it serves."
